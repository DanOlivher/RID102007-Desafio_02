# RID102007-Desafio_02

# Esse é um projeto de desenvolvimento de um site de clima-tempo, desenvolvido para o aprendizado de APIs, o que são e como utiliza-las. 

# Nesta projeto foi criado uma pagina, onde 2 APIs são usadas(consumidas), uma de CEP(onde mostra as informações de endereço) e outra de Clima(onde é mostrado a temperatura segundo as coordenadas colocada).

# Para utilizar essa paginas, você terá que preencher TODAS AS INFOMAÇÕES pedidas e aperta no botão, tendo em mente que deverá colocar as coordenadas da mesma localização do CEP, para ter mais precisão da temperatura do local. Caso contrario, a temperatura exibida na tela, será da localidade da respectiva Coordenada que colocou. O CEP deverá ser um valido, ou não terá retorno das informações pedidas.
